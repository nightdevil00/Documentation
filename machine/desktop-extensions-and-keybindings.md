# Desktop extensions and keybindings

`dconf` dump from this machine, exported as a gist and archived here so it
lives with everything else. Restoring it puts back every GNOME extension and
its settings, the keybindings, the theme and the input configuration.

Gist: https://gist.github.com/nightdevil00/85b9f5591a1dc5ee767bdc3b1bb6a45a
